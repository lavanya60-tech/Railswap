# Railswap 🚆

Railswap is a Train Ticket Resale System Web Application designed to help users buy and resell train tickets through a simple and user-friendly platform.

## Features

- User-friendly train ticket resale system
- Ticket listing and browsing
- Search and manage train tickets
- Simple and responsive web interface
- Organized frontend and backend structure

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
